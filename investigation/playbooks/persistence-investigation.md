# Registry Persistence Investigation Playbook

1. Identify the registry key/value and event type.
2. Record process, user, timestamp and registry data.
3. Determine whether the path is an autorun location.
4. Correlate with process creation and file creation events.
5. Check expected software installation or update activity.
6. Record the mechanism, evidence and confidence.
7. Use a lab snapshot or documented rollback for cleanup.
