# PowerShell Investigation Playbook

1. Confirm host, user, event time and original event record.
2. Review full command line, parent process, process GUID and related PowerShell operational events.
3. Search preceding and following process events on the host.
4. Identify files written and network/DNS events associated with the process.
5. Determine whether the command is approved administrative activity.
6. Document evidence, confidence, limitations and next steps.
7. Preserve evidence before response.
