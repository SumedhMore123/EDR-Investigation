# Detection Test Results

For each rule, record:
- Rule name and version.
- Test date and VM snapshot identifier.
- Simulation name and ATT&CK technique.
- Expected telemetry and observed telemetry.
- Alert result (pass / partial / fail).
- False-positive notes.
- Cleanup completion.
- Screenshots or sanitized evidence reference.

Do not mark a detection as validated until the test has actually been executed and evidence reviewed.
